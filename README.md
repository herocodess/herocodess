## 🚀 Things I've built

### [Postrun](https://postrun.app): the flight recorder for AI coding agents
Records every command, edit, file read and reply that Claude Code and Cline make, on your own machine. You review the session in a local app, sign it off, and share a redacted report. Free and open source on npm.
`TypeScript` `Node.js` `AI agents` `Local-first`
**[Website](https://postrun.app)** · **[Live demo](https://postrun.app/demo/)**

### [Whyloop](https://whyloop.app): AI mock interviews that teach
An AI interviewer plans an interview for your exact role, CV and job description. It asks follow-ups when an answer is shallow, grades every answer against one consistent rubric, and turns what you missed into hints, walkthroughs and audio lessons. Four interviewers on four LLM providers, in six languages.
`Next.js` `Supabase` `AI SDK` `Anthropic` `OpenAI` `xAI` `DeepSeek`
**[Website](https://whyloop.app)**

### [Driftlog](https://driftlog.dev): architectural drift detection
A local-first CLI that parses your code with tree-sitter and flags layer breaches, forbidden imports and circular dependencies against rules you define. Ships on npm and Homebrew.
`TypeScript` `tree-sitter` `CLI` `Developer tools`
**[Website](https://driftlog.dev)**

### Askwell: AI front desk for small businesses
Answers customer questions using only the business's own content (Instagram, price lists, website), cites the source on every reply, and hands serious leads to the owner's WhatsApp with the full chat attached.
`Next.js` `Supabase` `RAG` `WhatsApp`

### 🎮 Hustle World *(soft launch, coming soon)*
A multiplayer street-economy game that runs in the browser and is tuned for budget Android phones on 4G. Up to 60 players per street. A server-authoritative double-entry ledger tracks all the money, and each city is a config file.
`Three.js` `Colyseus` `TypeScript` `Supabase` `Real-time multiplayer`
