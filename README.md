### Products

**[Postrun](https://postrun.app)**: the flight recorder for AI coding agents<br>
Records every command, edit, file read and reply that Claude Code and Cline make, on your own machine. You review the session in a local app, sign it off, and share a redacted report. Free and open source on npm.<br>
<sub>TypeScript · Node.js · AI agents · Local-first</sub>

**[Whyloop](https://whyloop.app)**: AI mock interviews that teach<br>
An AI interviewer plans an interview for your exact role, CV and job description. It asks follow-ups when an answer is shallow, grades every answer against one consistent rubric, and turns what you missed into hints, walkthroughs and audio lessons. Four interviewers on four LLM providers, in six languages.<br>
<sub>Next.js · Supabase · AI SDK · Anthropic · OpenAI · xAI · DeepSeek</sub>

**[Driftlog](https://driftlog.dev)**: architectural drift detection<br>
A local-first CLI that parses your code with tree-sitter and flags layer breaches, forbidden imports and circular dependencies against rules you define. Ships on npm and Homebrew.<br>
<sub>TypeScript · tree-sitter · CLI · Developer tools</sub>
